系统参数配置

管理 WAF 全局开关、特征库匹配规则与客户端真实 IP 透传配置。

全局规则

—

控制 WAF 整体防护策略的启用与关闭，关闭后所有流量将直接放行。

特征库匹配

—

启用或关闭 SQL 注入、XSS 攻击等特征库规则匹配，关闭后仅依赖 IP/路径/请求头等策略。

全量日志

—

开启后记录所有请求日志，关闭后仅记录触发拦截规则的请求日志，可减少日志存储量。

登录有效期

—

设置登录会话 Token 的有效期限。到期后需重新登录，选择"永不过期"则 Token 持续有效直至手动退出。

真实 IP 配置

—

设置从反向代理或 CDN 获取客户端真实 IP 的请求头字段，如 X-Forwarded-For 或 X-Real-IP。
